# 视频号评论助手（Chrome 扩展）

在**你已登录的视频号助手后台**运行。读取评论数为 0 的视频（含完整描述），把**外部 AI 生成**的评论一键提交。

> 扩展本身**不调用任何 AI**。它只做三件事：读列表、导出列表给你、提交你粘贴回来的评论。

## 为什么这样做

视频号官方没有开放评论 API，只有视频号助手网页端背后的内部接口可用。扩展跑在页面里，请求与页面同源、自动携带你当前的登录 Cookie——不需要扫码、不需要复制 Cookie、凭证不出浏览器。

## 工作原理

1. **拉取**：内容脚本调用 `post_list` 接口，解析出每条视频的 `id` / 短标题 / 完整描述 / 评论数，筛出评论数为 0 的。
2. **导出**：把这些视频（含完整描述）导出为 JSON，供你粘贴给外部 AI（ChatGPT、Claude、TRAE 等）生成评论。
3. **提交**：把你粘贴回来的评论，通过 `create_comment` 接口提交到对应视频的评论区。

请求全部由内容脚本直接发起，与页面同源同 Cookie。扩展**不读取、不导出、不上传**任何凭证。

### 使用的接口

```
POST /micro/interaction/cgi-bin/mmfinderassistant-bin/post/post_list
POST /micro/interaction/cgi-bin/mmfinderassistant-bin/comment/create_comment
     ?_aid=<uuid>&_rid=<rid>&_pageUrl=<encodeURIComponent(页面地址)>
```

评论请求体：`exportId` 放目标视频 ID、`content` 放评论正文，`clientId` / `timestamp` 每次自动重新生成。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录（含 `manifest.json` 的那一层）
4. 打开 <https://channels.weixin.qq.com/platform/post/list>（确保已登录），页面右下角出现绿色「评论助手」按钮

## 使用步骤

### 第一步：拉取 0 评论视频

点「评论助手」→ 点「拉取 0 评论视频」。列表会显示评论数为 0 的视频，每条包含短标题、对象 ID 和完整描述（点描述可展开）。

### 第二步：交给外部 AI 生成评论

点「复制列表 JSON」，得到形如：

```json
[
  {
    "id": "export/UzFfBgAA...",
    "title": "分红到手 你怎么看这笔钱？",
    "description": "那条「分红到账」的短信……（完整正文）",
    "commentCount": 0
  }
]
```

把它连同你的要求（语气、字数、是否带话题标签等）一起发给外部 AI，让 AI 按 `id` 逐条给出评论正文。

### 第三步：粘贴并提交

1. 把 AI 生成的评论粘贴到对应视频的输入框（草稿会按视频 ID 自动保存，刷新页面不丢）；
2. 先保持「干跑」勾选，点「提交评论」→ 只显示将要发送的请求体，不真正提交；
3. 确认无误后取消勾选「干跑」，再点「提交评论」→ 真正提交。

## 隐私与安全

- 仓库不含任何账号 ID、finder id、Cookie 或凭证；
- 请求只发往 `channels.weixin.qq.com`，与页面同源，凭证不出浏览器；
- 不引入任何第三方脚本，无遥测、无埋点；
- 草稿只存在本机 `localStorage`。

## 已知限制

- 评论接口无公开文档，页面改版后接口路径或字段可能变化，需相应更新 `src/lib.js`；
- 若视频号助手网页端本身不支持作者给自己的视频发新评论，则无法通过接口完成；
- 频率请自行克制，避免短时间大量提交。

## 排障

- **提示「登录态已失效（errCode=300330 / 300334）」**：Cookie 里的会话已过期（`300330` 表示没有有效会话，`300334` 表示会话存在但已失效），扩展无法自动恢复。请到视频号助手**重新登录（重新扫码）**，再刷新本页重试。注意这与请求参数无关，不用改代码。
- **提示「接口返回不是 JSON」**：多是被重定向到登录页，或页面改版。先按上一条重新登录；仍不行再检查接口路径。

## 文件结构

```
manifest.json          MV3 清单
src/lib.js             纯逻辑：接口地址、请求体构造、响应解析（可在 Node 中单测）
src/content.js         内容脚本：悬浮面板 UI + 拉取/导出/提交
test/lib.test.mjs      逻辑层单元测试（node test/lib.test.mjs）
icons/icon128.png      扩展图标
```
